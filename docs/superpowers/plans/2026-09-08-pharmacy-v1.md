# Pharmacy V1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add thin device licensing, session/scan persistence, and private training assets (original + annotations JSON + overlay) while keeping Gemini/OpenRouter and customer-safe results only.

**Architecture:** Extend `server.js` with SQLite + local storage modules; gate APIs with device tokens when `POOSTA_LICENSE_REQUIRED=true`; frontend Activation screen + Bearer headers; never auto-retrain models.

**Tech Stack:** Node ESM, better-sqlite3 (fallback sql.js), sharp (optional overlay), existing React/Vite client, existing Gemini/OpenRouter/Python AI.

## Global Constraints

- No automatic model retraining from new scans — only collect assets under `data/scans/`.
- No SMS, admin UI, pharmacy dashboard, Redis, or live S3.
- Customer responses must never include overlay URLs or storage keys.
- `POOSTA_LICENSE_REQUIRED=false` by default for local dev.
- Spec: `docs/superpowers/specs/2026-09-08-pharmacy-v1-design.md`
