# Poosta — 10-item implementation status\n\n1. Real Skin Analysis — Vision endpoint + structured JSON + deterministic scoring.\n2. Real Face/Image Quality Detection — server-side vision quality gate + local UX.\n3. Face Scan UX — live camera, face oval guide, capture/gallery flow.\n4. Consent + Privacy — consent stored in Supabase, private thumbnail storage, export, delete-history, server-side account deletion.\n5. Real Product Database — 75-product local catalog + full Supabase seed for products/ingredients/skin types/concerns.\n6. Recommendation Engine — score by metrics, skin type, goals, Iran availability, sensitivity, safety and active conflicts.\n7. Real Supabase Integration — auth/profile/scan/product persistence and hydration are wired.\n8. Supabase schema mapping — corrected product IDs/categories/metadata and explicit DB-to-TS mapping.\n9. Real Authentication — email/SMS OTP send + verify + session bootstrap; local fallback only when Supabase is intentionally unconfigured.\n10. Medical safety/disclaimers — assessment-only language, pregnancy filtering, active-conflict warnings, and medical disclaimer UI.\n\n## Required environment\n\n- `VITE_SUPABASE_URL`\n- `VITE_SUPABASE_ANON_KEY`\n- `SUPABASE_URL` (backend)\n- `SUPABASE_SERVICE_ROLE_KEY` (backend only)\n- `GEMINI_API_KEY` (backend only)\n- `GEMINI_MODEL`\n\n## Supabase setup\n\n1. Run `supabase/schema.sql` on a new project, or perform a staged migration for an existing production DB.\n2. Configure Email OTP and/or SMS OTP in Supabase Auth.\n3. Run `npm run seed:products` with `SUPABASE_URL` and `SUPABASE_SERVICE_ROLE_KEY`.\n4. Start the API with `npm run api`, then the frontend with `npm run dev`.\n
